# YOLO26 Surveillance

Experimental YOLO26s ONNX graph-slicing project for Blue Iris and CodeProject.AI.

Development is taking place on the [`test` branch](../../tree/test). This `main` branch is reserved for the verified stable release.

The current test artifact intentionally retains a bicycle class for graph-slicing experimentation. The planned public surveillance set is person, car, truck, bus, motorcycle, cat and dog.

No stable release is published yet.
